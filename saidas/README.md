# saidas/

Pasta sugerida para as saídas da conferência: a planilha para o Conselho
Fiscal e o JSON para o agente, um par por mês. Exemplo:

```bash
conselho-fiscal receitas exemplo/2026-07/entradas.xlsx exemplo/2026-07/cora.xlsx \
                         exemplo/2026-07/stone.xlsx saidas/receitas_2026-07.xlsx
```

Gera `saidas/receitas_2026-07.xlsx` e `saidas/receitas_2026-07.json`.
